# OIBSIP - Python BMI Calculator

## Task by Oasis Infobyte - Level 1

A simple Python project that calculates Body Mass Index (BMI) based on height and weight.

### Features
- Takes Height and Weight as input
- Calculates BMI
- Shows Category (Underweight / Normal / Overweight / Obese)

### Formula Used
BMI = Weight (kg) / Height (m)^2
